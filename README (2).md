## Project overview
This project uses Exploratory Data Analysis (EDA) to explore how study habits and other student-related factors are associated with exam scores.

## Dataset
- **Name:** Student Performance Factors
- **Source:** [Kaggle dataset](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)
- **File:** `StudentPerformanceFactors.csv`
- **Notebook:** `student_performance_eda.ipynb`

Add the dataset as an input to your Kaggle Notebook before running the code. The notebook searches Kaggle's input folder for `StudentPerformanceFactors.csv`.

## What the notebook includes
1. Load and inspect the dataset
2. Check missing values and duplicate rows
3. Handle missing values using median for numerical columns and mode for categorical columns
4. Basic numerical summary
5. Histogram of exam scores
6. Density plot of exam scores
7. Bar chart of motivation levels
8. Boxplot of exam scores
9. Exam scores across attendance groups
10. Scatter plot of study hours and exam scores
11. Line plot of average scores across study-hour groups
12. Correlation heatmap
